The `abpframework/abp` repository is a single .NET + Node monorepo that contains the full framework (152 packages), 19 prebuilt application modules, 6 project templates (DDD layered, single-layer, console, module, MAUI, WPF) and the matching Angular / Vue / Razor NPM packs. This page is the canonical map. Every directory below is rooted at the repository root and corresponds to a deployable unit — NuGet package, NPM package, template, or build script. Cross-links point to the deeper pages.

## Top-level directories

| Directory | Role | Wiki |
| --- | --- | --- |
| `framework/` | 152 `Volo.Abp.*` NuGet packages. The framework itself. | `/framework` |
| `modules/` | 19 prebuilt application modules (Identity, Account, CmsKit…). | `/modules` |
| `templates/` | Project templates used by `abp new`. | `/templates` |
| `npm/` | Lerna monorepo of Angular packages (`ng-packs/`) and Razor/Vue runtime packs (`packs/`). | `/npm` |
| `tools/` | Standalone build / changelog / NuGet helper tools. | `/tooling` |
| `build/` | PowerShell scripts that build the entire repo (`build-all.ps1`, `build-all-release.ps1`, `test-all.ps1`). | `/tooling/build` |

| `studio/source-codes/` | Same bundle, but consumed by ABP Studio. | `/tooling/studio` |

## `modules/` — 19 prebuilt application modules

Every module is itself a mini-monorepo following the layered shape:

```text
modules/<name>/
├── src/
│   ├── Volo.<Name>.Domain.Shared
│   ├── Volo.<Name>.Domain
│   ├── Volo.<Name>.Application.Contracts
│   ├── Volo.<Name>.Application
│   ├── Volo.<Name>.HttpApi
│   ├── Volo.<Name>.HttpApi.Client
│   ├── Volo.<Name>.Web
│   ├── Volo.<Name>.Blazor (Server / WebAssembly variants)
│   ├── Volo.<Name>.EntityFrameworkCore
```

## `source-code/` and `studio/source-codes/`

Both folders package whole modules as "source-code" .csproj bundles consumed by ABP Commercial subscribers or ABP Studio. The lists overlap and include:

```text
Volo.Abp.Account.SourceCode
Volo.Abp.AuditLogging.SourceCode
Volo.Abp.BackgroundJobs.SourceCode
Volo.Abp.BasicTheme.SourceCode
Volo.Abp.BlobStoring.Database.SourceCode
Volo.Abp.FeatureManagement.SourceCode
Volo.Abp.Identity.SourceCode
Volo.Abp.IdentityServer.SourceCode
Volo.Abp.OpenIddict.SourceCode
Volo.Abp.PermissionManagement.SourceCode
Volo.Abp.SettingManagement.SourceCode
Volo.Abp.TenantManagement.SourceCode
Volo.Abp.Users.SourceCode
Volo.Abp.VirtualFileExplorer.SourceCode
Volo.Blogging.SourceCode
Volo.ClientSimulation.SourceCode
Volo.CmsKit.SourceCode
Volo.Docs.SourceCode
```

Each `*.SourceCode/` folder is just a shim `.csproj` that references the matching `modules/<name>/src/*` projects via `ProjectReference` so the consumer ends up with full sources instead of a binary NuGet package.

<Note>
There is also a separate solution file `source-code/SourceCodes.sln` that bundles all of the above into a single Visual Studio solution for the team that maintains the commercial offering.
</Note>
