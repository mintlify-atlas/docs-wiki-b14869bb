ABP publishes thirty-something `@abp/<library>` packages whose entire purpose is to make
`abp install-libs` aware of a third-party JavaScript/CSS distribution. Each one is a tiny tarball
containing a `package.json` (declaring the upstream library as a peer dependency), an optional
`README.md`, and a single `abp.resourcemapping.js` describing which files to copy into
`wwwroot/libs/`. A handful (`@abp/bootstrap`, `@abp/jquery`, `@abp/luxon`, `@abp/qrcode`, `@abp/tui-editor`)
also ship a small `src/` directory with ABP-specific shims.

This page is the **catalog**. Use it to look up what each pack does and where its files end up.

## The `abp.resourcemapping.js` DSL

Every pack uses the same one-or-two-key shape. Real examples:

```js
// @abp/toastr — simplest case
module.exports = {
    mappings: {
        "@node_modules/toastr/build/*.*": "@libs/toastr/"
    }
};
```

```js
// @abp/select2 — split CSS/JS, localization files
module.exports = {
    mappings: {
        "@node_modules/select2/dist/css/select2.min.css":     "@libs/select2/css/",
        "@node_modules/select2/dist/js/select2.min.js":       "@libs/select2/js/",
        "@node_modules/select2/dist/js/select2.full.min.js":  "@libs/select2/js/",
        "@node_modules/select2/dist/js/i18n/*.js":            "@libs/select2/js/i18n/"
    }
};
```

```js
// @abp/bootstrap — vanilla + RTL + ABP's own enable.popovers/enable.tooltips shims
module.exports = {
    mappings: {
        "@node_modules/bootstrap/dist/css/bootstrap.css*":         "@libs/bootstrap/css/",
        "@node_modules/bootstrap/dist/css/bootstrap.min.css*":     "@libs/bootstrap/css/",
        "@node_modules/bootstrap/dist/css/bootstrap.rtl.css*":     "@libs/bootstrap/css/",
        "@node_modules/bootstrap/dist/css/bootstrap.rtl.min.css*": "@libs/bootstrap/css/",
        "@node_modules/bootstrap/dist/js/bootstrap.bundle*":       "@libs/bootstrap/js/",
        "@node_modules/@abp/bootstrap/src/*.*":                    "@libs/bootstrap/js/"
    }
};
```

Conventions:

- `@node_modules/` ⇒ project's `node_modules/` (alias).
- `@libs/` ⇒ project's `wwwroot/libs/` (alias).
- Trailing `/` on the value preserves the source filename.
- `*` matches a single segment; `**` matches any depth.
- `.css*` covers `.css`, `.css.map`, `.css.min.map`, etc.

See [`@abp/aspnetcore.mvc.ui`](/npm/aspnetcore-mvc-ui) for the Gulp engine that consumes these files.

## Catalog

### Core jQuery, Bootstrap & validation

| Pack                                 | Upstream                              | Lands under                              |
| ------------------------------------ | ------------------------------------- | ---------------------------------------- |
| `@abp/jquery`                        | jQuery 3.6                            | `libs/jquery/`, `libs/abp/jquery/`       |
| `@abp/bootstrap`                     | Bootstrap 5                           | `libs/bootstrap/{css,js}/`               |
| `@abp/jquery-form`                   | jquery.form (ABP-bundled `min.js`)    | `libs/jquery-form/`                      |
| `@abp/jquery-validation`             | jquery-validation                     | `libs/jquery-validation/`                |
| `@abp/jquery-validation-unobtrusive` | aspnet-jquery-validate-unobtrusive    | `libs/jquery-validation-unobtrusive/`    |

**`@abp/jquery`** ships an `abp.jquery.js` (`src/abp.jquery.js`) that overrides
`abp.message._showMessage`, `abp.message.confirm`, and `abp.utils.isFunction` with jQuery-backed
implementations and adds an `abp.dom` MutationObserver namespace. **`@abp/bootstrap`** similarly
ships `bootstrap.enable.popovers.everywhere.js` and `bootstrap.enable.tooltips.everywhere.js` that
auto-initialise the corresponding components on every page.

### Date / time / locale

| Pack                  | Upstream      | Notes                                                  |
| --------------------- | ------------- | ------------------------------------------------------ |
| `@abp/luxon`          | Luxon 3       | Plus an `abp.luxon.js` shim that wires `abp.timing.*`  |
| `@abp/moment`         | Moment.js     | Locale files included; `min/moment.min.js`             |
| `@abp/timeago`        | jquery.timeago| Plus locales                                           |

`@abp/luxon` is the strategic choice — ABP uses it whenever a Razor page does timezone-aware formatting.
`@abp/moment` is kept for backwards compatibility with older modules. The Luxon shim's start:

```js
// @abp/luxon/src/abp.luxon.js
var abp = abp || {};
(function () {
    if (!luxon) {
        throw "abp/luxon library requires the luxon library included to the page!";
    }
    abp.timing = abp.timing || {};
    // adds abp.timing.convertFieldsToIsoDate, etc.
})();
```

### Notifications & dialogs

| Pack             | Upstream     | Purpose                                       |
| ---------------- | ------------ | --------------------------------------------- |
| `@abp/toastr`    | Toastr       | Backs `abp.notify.*` (see [`@abp/core`](/npm/core)) |
| `@abp/sweetalert2`| SweetAlert2 | Backs `abp.message.*`                         |

The ABP-side shims (`abp-toastr.js`, `abp-sweetalert2.js`) ship as static files inside

Note **`@abp/tui-editor`'s** resource mapping is special — it ships an ABP-curated bundle rather than
the upstream `dist/`:

```js
// @abp/tui-editor/abp.resourcemapping.js
module.exports = {
    mappings: {
        "@node_modules/@abp/tui-editor/src/*.*": "@libs/tui-editor/"
    }
};
```

Inside `src/` you'll find:

```text
@abp/tui-editor/src/
├── toastui-editor-all.min.js
├── toastui-editor.min.css
├── toastui-editor-plugin-code-syntax-highlight-all.min.js
└── toastui-editor-plugin-code-syntax-highlight.min.css
```

This is the rare case where ABP **re-distributes** the third-party files inside its own pack rather
than glob-copying them out of the upstream `node_modules`. Same applies to `@abp/qrcode` (which
embeds the `davidshimjs/qrcodejs` script directly under `src/`) and `@abp/jquery-form` (which ships
the minified jquery.form build under `src/jquery.form.min.js`).

`@abp/signalr` is interesting because its source is a scoped Microsoft package
(`@microsoft/signalr`):

```js
module.exports = {
    mappings: {
        "@node_modules/@microsoft/signalr/dist/browser/*.*": "@libs/signalr/browser/"
    }
};
```

This ships ESM, UMD, and `*.d.ts` flavours so any `<script type="module">` consumer can pick the right
distribution.

## Anatomy of the simpler packs

### `@abp/jquery`

```json
{ "name": "@abp/jquery", "version": "7.4.0",
  "dependencies": { "@abp/core": "~7.4.0", "jquery": "~3.6.0" } }
```

```js
// abp.resourcemapping.js
module.exports = {
    mappings: {
        "@node_modules/jquery/dist/jquery.js":     "@libs/jquery/",
        "@node_modules/@abp/jquery/src/*.*":       "@libs/abp/jquery/"
    }
};
```

```text
src/
└── abp.jquery.js     ← installs $.fn extensions and abp.dom.* MutationObserver
```

The `abp.jquery.js` file is the canonical example of an ABP "shim" — it `require`s jQuery indirectly
(via `if (!$) { throw }`), overrides `abp.message._showMessage` with `alert(...)` as a fallback, and
adds `abp.dom.onNodeAdded` / `abp.dom.onNodeRemoved` event helpers.

### `@abp/luxon`

```text
src/
└── abp.luxon.js      ← wires abp.timing.*; needs window.luxon present
```

The shim adds `abp.timing.convertFieldsToIsoDate(form, fields)` so a form submitted via `abpAjaxForm`
re-encodes its `<input type="date">` and `<input type="datetime-local">` fields to ISO 8601 before
posting.

### `@abp/qrcode`

Ships the vendored `qrcodejs` script under `src/`, exposing the `QRCode` global. Used by the user
profile QR-code modal for TOTP enrolment.

## Using a third-party pack from a Razor view

You **don't** generally reference the npm pack directly — your theme's bundle contributor includes
the files for you. But when you want to use one of these libraries in a custom page:

```html
@page
<button id="copy" class="btn btn-secondary" data-clipboard-target="#mytext">Copy</button>
<pre id="mytext">Hello, world!</pre>

@section Scripts {
    <script src="~/libs/clipboard/clipboard.min.js"></script>
    <script>
        new ClipboardJS('#copy').on('success', function () {
            abp.notify.success('Copied');
        });
    </script>
}
```

The path `~/libs/clipboard/clipboard.min.js` exists because `@abp/clipboard`'s mapping copied it
there. Add the library to your project's `package.json` (or rely on a transitive pack such as
`@abp/virtual-file-explorer` which already depends on it).

## Gotchas

- **Don't fetch upstream libraries from CDNs and reference both.** You'll either ship two copies or
  worse, two incompatible versions of jQuery. Pick one.
- **Bundle contributors are theme-specific.** When you switch from the Basic theme to LeptonX, the
  *same* `wwwroot/libs/` populates, but the bundle contributor changes which files are emitted in
  `<script>`/`<link>` tags. If a page used to "just work" and breaks after a theme swap, look at the
  new bundle contributor.
- **`abp install-libs` deletes by default before copying.** The Gulp engine's `cleanDirsAndFiles`
  honours each pack's `clean` array; check that your custom additions to `wwwroot/libs/` aren't
  matched by any pack's clean pattern.
- **Glob ordering matters when packs overlap.** If `@abp/bootstrap` copies `bootstrap.min.css` into
  `libs/bootstrap/css/` and a custom pack copies a different `bootstrap.min.css` into the same
  destination, whichever runs last wins. The order is non-deterministic — namespace your destinations
  if you ship a customised distribution.
- **CSS `@import` URLs are not rewritten.** When you copy a third-party CSS that `@import`s a
  sub-file, the relative path is preserved. If the source's `**` glob misses the imported file you'll
  get a 404 — verify by reading the upstream CSS for `@import`/`url(...)` references.
- **The CLI deduplicates `node_modules` traversal.** A pack listed multiple times in the dependency
  tree only gets its mapping evaluated once. Don't rely on side effects of duplicated mappings.
- **No TypeScript declarations.** None of these packs ship `.d.ts` files (`@abp/signalr` carries the
  upstream Microsoft `.d.ts` but doesn't author its own). If you want types, import directly from the
  underlying npm package in your TypeScript code.
- **`@abp/utils` is the odd one out** — it ships a full UMD bundle, not a mapping over a third-party
  library. See [`@abp/utils`](/npm/utils).
