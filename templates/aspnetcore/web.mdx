`MyCompanyName.MyProjectName.Web` is the **single-process MVC/Razor Pages host** generated by `abp new ... -u mvc` (without the `--tiered` switch). It contains the application's pages, menu contributor, branding provider, AutoMapper profiles for view models, and the module class that wires everything together. The same process serves the UI, the Auto API controllers, and the OpenIddict-based authentication server.

This is the simplest deployment topology in ABP: one host, one connection string, one URL. For multi-process MVC see [Web.Host](/templates/aspnetcore/web-host).

## Module class

```csharp
[DependsOn(
    typeof(MyProjectNameHttpApiModule),
    typeof(MyProjectNameApplicationModule),
    typeof(MyProjectNameEntityFrameworkCoreModule),
    typeof(AbpAutofacModule),
    typeof(AbpIdentityWebModule),
    typeof(AbpSettingManagementWebModule),
    typeof(AbpAccountWebOpenIddictModule),
    typeof(AbpAspNetCoreMvcUiLeptonXLiteThemeModule),
    typeof(AbpTenantManagementWebModule),
    typeof(AbpAspNetCoreSerilogModule),
    typeof(AbpSwashbuckleModule))]
public class MyProjectNameWebModule : AbpModule
{
    public override void PreConfigureServices(ServiceConfigurationContext context)
    {
        context.Services.PreConfigure<AbpMvcDataAnnotationsLocalizationOptions>(options =>
        {
            options.AddAssemblyResource(
                typeof(MyProjectNameResource),
                typeof(MyProjectNameDomainModule).Assembly,
                typeof(MyProjectNameDomainSharedModule).Assembly,
                typeof(MyProjectNameApplicationModule).Assembly,
                typeof(MyProjectNameApplicationContractsModule).Assembly,
                typeof(MyProjectNameWebModule).Assembly);
        });

        PreConfigure<OpenIddictBuilder>(builder =>
        {
            builder.AddValidation(options =>
            {
                options.AddAudiences("MyProjectName");
                options.UseLocalServer();
                options.UseAspNetCore();
            });
        });
    }
    // ConfigureServices + OnApplicationInitialization ...
}
```

Two key configurations occur in `PreConfigureServices`:

1. **Data annotations localization** — points every `DataAnnotationsLocalization` lookup at `MyProjectNameResource`, so `[Required(ErrorMessageResourceName = "...")]` resolves through the same JSON files as the rest of the UI.
2. **OpenIddict validation** — the host is also the issuer; `UseLocalServer()` skips network discovery.

### Authentication forwarding

```csharp
private void ConfigureAuthentication(ServiceConfigurationContext context)
{
    context.Services.ForwardIdentityAuthenticationForBearer(
        OpenIddictValidationAspNetCoreDefaults.AuthenticationScheme);
}
```

This bridges the cookie-based identity used by Razor Pages to the bearer scheme used by the API endpoints exposed from the same host.

### Virtual file system

In development the module replaces every embedded resource of the depended ABP modules with the physical path under `framework/` and `modules/`. The bottom four lines pin the project's own modules to their on-disk paths:

```csharp
options.FileSets.ReplaceEmbeddedByPhysical<MyProjectNameDomainSharedModule>(
    Path.Combine(hostingEnvironment.ContentRootPath,
        $"..{Path.DirectorySeparatorChar}MyCompanyName.MyProjectName.Domain.Shared"));
options.FileSets.ReplaceEmbeddedByPhysical<MyProjectNameDomainModule>(...);
options.FileSets.ReplaceEmbeddedByPhysical<MyProjectNameApplicationContractsModule>(...);
options.FileSets.ReplaceEmbeddedByPhysical<MyProjectNameApplicationModule>(...);
options.FileSets.ReplaceEmbeddedByPhysical<MyProjectNameWebModule>(hostingEnvironment.ContentRootPath);
```

You can now edit a Razor Page or JSON localization file and refresh the browser without a re-build.

### Navigation

```csharp
Configure<AbpNavigationOptions>(options =>
{
    options.MenuContributors.Add(new MyProjectNameMenuContributor());
});
```

`MyProjectNameMenuContributor` inserts the "Home" item at order 0, optionally hides the `TenantManagement` menu when `MultiTenancyConsts.IsEnabled` is `false`, and orders the `Identity` and `SettingManagement` groups beneath it.

### Auto API controllers + Swagger

```csharp
Configure<AbpAspNetCoreMvcOptions>(options =>
{
    options.ConventionalControllers.Create(typeof(MyProjectNameApplicationModule).Assembly);
});

services.AddAbpSwaggerGen(options =>
{
    options.SwaggerDoc("v1", new OpenApiInfo { Title = "MyProjectName API", Version = "v1" });
    options.DocInclusionPredicate((docName, description) => true);
    options.CustomSchemaIds(type => type.FullName);
});
```

`AddAbpSwaggerGen` (note: **without** `WithOAuth`) is enough because this host's identity server lives in the same process and Swagger UI talks to it through cookie auth.

## Program.cs

Identical structure to the other hosts: configure Serilog, build a `WebApplicationBuilder`, call `UseAutofac()`, register the ABP application via `AddApplicationAsync<MyProjectNameWebModule>()`, and run.

## Key types

### MyProjectNameBrandingProvider

`IBrandingProvider` implementation read by the LeptonX Lite theme to render the application name in the top bar:

```csharp
public class MyProjectNameBrandingProvider : DefaultBrandingProvider
{
    public override string AppName => "MyProjectName";
}
```

### MyProjectNameMenus / MyProjectNameMenuContributor

`MyProjectNameMenus` is a constants container (only `Home` in the template). The contributor inserts a Home item, reorders the administration sub-menus and removes the Tenant Management menu if multi-tenancy is disabled.

### MyProjectNameWebAutoMapperProfile

Empty by default. Add view-model -> DTO mappings here that are only relevant to the MVC views; reusing the application-layer profiles is encouraged for symmetry.

## Gotchas

- **A single host means a single set of secrets.** Connection strings, OpenIddict signing keys, and Redis configuration all share one `appsettings.json`. Scaling out horizontally still requires Redis-backed data protection so cookies issued by replica A are decryptable by replica B.
- **`UseAuthentication` -> `UseAbpOpenIddictValidation` -> `UseMultiTenancy` order matters.** Validation has to run *after* `UseAuthentication` so JWTs (used for the API portion) are processed; multi-tenancy runs after so claims like `tenantid` are available.
- **`PreConfigureServices` runs for every dependent module.** If you add a new module dependency that *also* configures `AbpMvcDataAnnotationsLocalizationOptions` make sure both calls accumulate (`AddAssemblyResource` is additive).
- **Don't reference `HttpApi.Client` here.** Doing so swaps the in-process application services for HTTP proxies, which then call back into the same host over the network — a self-inflicted distributed system.
- **The Swagger UI does not include the OAuth flow** in this template. Calling an `[Authorize]` endpoint from Swagger requires you to authenticate via the browser first (the cookie carries through). Replace `AddAbpSwaggerGen` with `AddAbpSwaggerGenWithOAuth` if you want the "Authorize" button.
- **`Web.Public` and `Web.Tiered` are NOT generated by the open-source template.** They are part of ABP Commercial. The open-source `Web` host already runs as a stand-alone app; for the split tiered version see [Web.Host](/templates/aspnetcore/web-host).
