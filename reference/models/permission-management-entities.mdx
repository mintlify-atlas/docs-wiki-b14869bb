The Permission Management module persists two distinct concerns:

1. **Permission grants** — runtime "this provider granted this permission" rows authored at administration time (`PermissionGrant`).
2. **Permission definitions** — design-time metadata describing every permission and group, synchronised from in-memory `IPermissionDefinitionProvider`s into the database by `StaticPermissionSaver` (`PermissionDefinitionRecord`, `PermissionGroupDefinitionRecord`).

Source path: `modules/permission-management/src/Volo.Abp.PermissionManagement.Domain/Volo/Abp/PermissionManagement/`.

## `PermissionGrant`

Base: `Entity<Guid>` + `IMultiTenant`. Each row says "permission `Name` is granted by provider `ProviderName` to key `ProviderKey`".

```csharp
public class PermissionGrant : Entity<Guid>, IMultiTenant
{
    public virtual Guid? TenantId { get; protected set; }
    [NotNull] public virtual string Name { get; protected set; }
    [NotNull] public virtual string ProviderName { get; protected set; }
    [CanBeNull] public virtual string ProviderKey { get; protected internal set; }

    public PermissionGrant(Guid id, string name, string providerName, string providerKey, Guid? tenantId = null)
    {
        Id = id;
        Name = Check.NotNullOrWhiteSpace(name, nameof(name));
        ProviderName = Check.NotNullOrWhiteSpace(providerName, nameof(providerName));
        ProviderKey = providerKey;
        TenantId = tenantId;
    }
}
```

| Property        | Type     | Notes                                                              |
| --------------- | -------- | ------------------------------------------------------------------ |
| `Id`            | `Guid`   | PK                                                                  |
| `TenantId`      | `Guid?`  | Multi-tenant filter                                                 |
| `Name`          | `string` | Permission name (`AbpIdentity.Roles.Create`, …)                    |
| `ProviderName`  | `string` | `"R"` (role), `"U"` (user), `"C"` (client), `"G"` (group), custom    |
| `ProviderKey`   | `string` | Identity of the principal — role name, user id, client id, etc.    |

### Indexes

- `IX_AbpPermissionGrants_TenantId_Name_ProviderName_ProviderKey` (unique)

### How it is read

`PermissionGrantRepository.FindAsync(name, providerName, providerKey, tenantId)` is queried by `PermissionStore`, which is cached by `IDistributedCache<PermissionGrantCacheItem>`. The cache key is materialised by `PermissionGrantCacheItem.CalculateCacheKey()`.

## `PermissionDefinitionRecord`

Base: `BasicAggregateRoot<Guid>` + `IHasExtraProperties`. The serialized form of an in-memory `PermissionDefinition`.

```csharp
public class PermissionDefinitionRecord : BasicAggregateRoot<Guid>, IHasExtraProperties
{
    public string GroupName { get; set; }
    public string Name { get; set; }
    public string ParentName { get; set; }
    public string DisplayName { get; set; }
    public bool IsEnabled { get; set; }
    public MultiTenancySides MultiTenancySide { get; set; }
    public string Providers { get; set; }      // comma-separated allowed providers
    public string StateCheckers { get; set; }  // serialized state-checker info
    public ExtraPropertyDictionary ExtraProperties { get; protected set; }
}
```

| Property            | Type                  | Constraints (`PermissionDefinitionRecordConsts`)                 |
| ------------------- | --------------------- | ---------------------------------------------------------------- |
| `GroupName`         | `string`              | `MaxNameLength` (128)                                            |
| `Name`              | `string`              | `MaxNameLength` (128) — unique within group                       |
| `ParentName`        | `string`              | `MaxNameLength` (128) — optional, for hierarchy                  |
| `DisplayName`       | `string`              | `MaxDisplayNameLength` (256)                                     |
| `IsEnabled`         | `bool`                | Default `true`                                                   |
| `MultiTenancySide`  | `MultiTenancySides`   | Flags: `Host`, `Tenant`, `Both`                                  |
| `Providers`         | `string`              | Comma-separated provider names — empty means all providers      |
| `StateCheckers`     | `string`              | Serialized list of permission state-checker types               |
| `ExtraProperties`   | `ExtraPropertyDictionary` | Object-extension bucket                                       |

### `HasSameData` / `Patch`

The class exposes a value-equality check used by `StaticPermissionSaver` to decide whether the in-memory definition has drifted from the database row, and a `Patch` mutator that copies only the changed fields. Both honour `ExtraProperties`:

```csharp
public bool HasSameData(PermissionDefinitionRecord otherRecord)
{
    if (Name != otherRecord.Name) return false;
    if (GroupName != otherRecord.GroupName) return false;
    // … other scalar fields …
    if (!this.HasSameExtraProperties(otherRecord)) return false;
    return true;
}
```

## Integration points

- `PermissionStore` reads `PermissionGrant` rows through `IPermissionGrantRepository`, caches them via `PermissionGrantCacheItem` and `PermissionGrantCacheItemInvalidator`.
- `StaticPermissionSaver` reconciles `PermissionDefinitionRecord` / `PermissionGroupDefinitionRecord` with the in-memory `IPermissionDefinitionContext` during application startup (driven by `IStaticPermissionSaver`).
- `DynamicPermissionDefinitionStore` reads the database records and projects them back into runtime `PermissionDefinition`s for hosts that opted into dynamic permissions (`AbpPermissionOptions.IsDynamicPermissionStoreEnabled = true`).
